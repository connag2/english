# English Codex Prompt Kit

이 저장소는 **Codex에서 바로 붙여 넣어 사용할 수 있는 프롬프트 모음**을 관리하기 위한 공간입니다.

## 포함 문서
- `CODEX_PROMPT_KR.md`: 한국어 기준 최종 영단어 암기 프로그램 생성 프롬프트.

## 사용 방법
1. `CODEX_PROMPT_KR.md` 내용을 복사합니다.
2. Codex 대화창에 그대로 붙여 넣습니다.
3. 필요 시 기술 스택/파일 구조/기능 우선순위만 수정해서 사용합니다.

## 목적
- 단어 입력이 쉬운 영단어 암기 프로그램을 빠르게 생성
- 자동 복습(SRS)과 오답 반복이 포함된 기본 학습 흐름 확보
- UI 가독성과 안정성을 우선한 구현 가이드 제공
